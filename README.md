# Nuvio AIO Bridge 🌉

> A stateless middleware to synchronize watch progress, history, and libraries between [AIOStreams](https://github.com/Viren070/AIOStreams) and Nuvio.

🚧 **Work in Progress:** This project is currently in the initial design and setup phase.

Please refer to the [SPECS.md](SPECS.md) file for the architectural design, data flow, and development roadmap.

## Tech Stack

* **Backend:** Go (Golang)

* **Authentication:** Stateless (AES-256-GCM via URL config)

* **Deployment:** Docker
